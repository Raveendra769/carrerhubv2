# CareerHub

CareerHub is a full-stack job portal where candidates can search and apply for jobs, and recruiters can post and manage job listings.

## Features

- User authentication (JWT)
- Candidate and recruiter roles
- Job posting
- Job applications
- Resume upload
- Protected routes
- Responsive UI

## Tech Stack

### Frontend
- React
- Vite
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- JWT
- TypeScript

## Folder Structure

```
CareerHub/
├── backend/
└── frontend-shell/
```

## Installation

### Clone the repository

```bash
git clone https://github.com/Raveendra769/carrerhubv2.git
```

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend-shell
npm install
npm run dev
```
